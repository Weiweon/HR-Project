# HR-Project 使用說明

此資料夾是正式版本，也是可攜帶版本。要帶去公司或其他電腦使用時，請整個複製 `HR-Project` 資料夾。

## 開啟方式

1. 進入 `HR-Project` 資料夾。
2. 直接雙擊 `index.html`。
3. 在網頁中匯入公司系統匯出的 Excel。

## 申請與核給新版

開啟 `approval.html`，匯入含「核可｜加班單申請」與「未核可｜加班單申請」的新版作業檔。原版 `index.html` 保留，兩版頂端可互相切換。

- 申請先採未核可 E 欄，加上核可表未重複的案件；核給只取核可 L 欄。
- 金額先取核可 M 欄，空白才依本人當月時薪估算核給部分。0 元仍為有效金額。
- 排班 AH 欄不參與新版加班統計。
- 管理摘要會固定於上方，窄螢幕可左右捲動摘要。桌面月曆維持每週七天並排、沒有橫向拉桿；長標籤必要時換行，手機才改日期分列。
- 桌面為左側月曆、右側日期明細，點日期直接更新右側；窄視窗才將明細移到下方。
- 深紅標籤以「超出日/月延展工時無核給」摘要呈現，退單與簽核紀錄仍為核給原因依據。
- 加班姓名多了「大林」院區註記時，可對應同名、同月份時薪；M 欄有有效金額仍優先。
- 明細畫面隱藏來源欄位與列號；匯出的明細 CSV 保留完整來源。
- 「簽到晚，起始時間往前推估半小時」完整呈現為單一標籤，只是文字註記，不會改變稽核時間與金額。
- 本次 1151018 作業檔的無姓名汽車紀錄已依確認自動對應人員，無須另選；其他檔案不沿用此特定對應。
- 公司與家中使用均需整包攜帶 `HR-Project`，包含新增的 `approval.html`、`approval.js` 及既有共用檔案。Excel 另行保密攜帶，不加入 GitHub。

## 檔案說明

- `index.html`：網頁入口。
- `approval.html`：申請與核給新版入口。
- `approval.js`：新版申請／核給配對、金額來源及新版呈現。
- `app.js`：Excel 匯入、加班費估算與異常判斷邏輯。
- `styles.css`：畫面樣式。
- `vendor/xlsx.full.min.js`：本機 Excel 解析函式庫。

## 維護原則

- 後續程式修改都以 `HR-Project` 內檔案為準。
- 外層資料夾主要保留 Git、需求文件、變更紀錄與 Excel 原始資料。

## 注意事項

- `http://127.0.0.1:8765/index.html` 只有在該台電腦已啟動本機網頁服務時才可使用。
- 若只是帶去公司使用，通常直接雙擊 `index.html` 即可。
- Excel 資料只在本機瀏覽器處理，不會上傳。
