# 心外異常工時與加班費

這是獨立的新版本。原本 `HR-Project` 保持不變。

目前資料夾為 `心外｜11501-11510異常工時與加班費`（原名 `心外異常工時與加班費`）。

## 開啟與匯入

1. 直接開啟本資料夾的 `index.html`，不需安裝或啟動伺服器。
2. 「匯入差勤 Excel」選新版差勤工作簿。
3. 「匯入手術／ECMO」選手術明細工作簿。兩檔匯入順序不限。
4. 選月份、人員，點日期查看右側的核給倍率、出勤佐證與手術時間。異常選單可篩「手術／ECMO 待覆核」。
5. 匯出摘要或明細 CSV，供後續覆核。重新整理網頁後須重新匯入原檔。

## 更新後開啟

- 更新程式後，先關閉原來的月曆分頁，再開啟本資料夾的 `index.html`。目前右上角應顯示 `本機處理 · v4.4`。
- 再匯入差勤與手術兩份 Excel。只在舊分頁重新匯入 Excel，仍會使用該分頁原本載入的程式。
- 重新整理不會修改原始 Excel，但會清除這一頁已匯入的暫存資料；需重新匯入。

帶往公司或家中時，整包複製本資料夾，保留 `vendor` 及所有程式檔，包含本機 `private-settings.js`。Excel 不必放進程式資料夾。

## 姓名與時薪設定

- 已確認的回任姓名對照會合併為同一人；選單只列正式姓名，仍可查回任前後資料。明細 CSV 保留原始人員名稱。
- 已確認的特定月份時薪優先使用本機設定，其餘依 Excel 的本人當月時薪。不跨人、跨月借用。
- 私人對照與時薪在 `private-settings.js`，此檔不納入 Git；程式庫只保留空白 `private-settings.example.js`。只下載 Git 版本不會取得私人設定，需在自己的電腦補回該檔。

## 欄位定義

- 未核可 E 與核可表未重複案件 F：全部申請時數。
- 核可 K～O 加總：核給時數；申請扣核給為未核給。
- 加班費：本人當月時薪 × K、L、M、N、O 各欄時數 × 1、1.334、1.667、2.667、1.667。各段進位至整元後相加。
- O 為應稅段，與 M 分開顯示，但不在本工具計算扣繳稅額。
- 不再讀取 M 為金額，不把 F 的未核給差額補算加班費，排班 AH 不參與加班總數。
- 已核給但缺本人當月時薪會標示「待補」，不借用其他員工或月份的時薪。

## 手術比對

- T／U 與加班起訖依時間直接比較，不把病患姓名視為同仁姓名。
- 相符／涵蓋是時段佐證；部分重疊、無重疊需補其他工作或術前術後作業紀錄。
- T=U 只當時間點；不延伸成整段出勤。
- 多案重疊不重複累計覆蓋時數。來源沒有同仁身分，不能僅憑時段認定特定同仁是否實際在場或申報不實。
- 月曆保留少量重點時間，右側與明細 CSV 可看完整紀錄。明細不新增病患姓名或病歷號展示。
- 有手術紀錄但未涵蓋加班起訖時，列出執行時間及「與加班起訖時間不符」標籤。沒有對應時段時，右側顯示「未找到與加班起訖相符之執行時段，須補其他佐證。」
- 下方清單的缺簽到退僅顯示標籤，不再重複長句；有實際手術佐證才補列執行時間。
- 相同起訖不符標籤一律粉紅底紅字；只有時間點仍列為時間點，不推算成完整執行區間。
- 沒有對應時段時，補列加班起始日當日最接近的手術資料供比較，標明「當日最接近」，不因此認定加班已獲佐證。
- 已相符或涵蓋加班的正常手術標籤不再顯示，右側仍可查看實際執行時間。
- 下方異常清單不再重複顯示一般「有未核給時數」標籤及原因待確認長句；核給／未核給欄位、具體額度或資料異常提示仍保留。

## 資料保密

資料只在本機瀏覽器記憶體處理，沒有上傳或雲端儲存。程式不含 Excel 或病患資料。原始檔與 CSV 仍須依公司權限及保密規範管理。

本機 `private-settings.js` 含使用者確認的私人設定，整包攜帶請注意存取權限。發布公開網站時務必排除此檔，不可直接上傳整個本機資料夾；`.gitignore` 只負責排除 Git，不會阻止其他上傳方式。
