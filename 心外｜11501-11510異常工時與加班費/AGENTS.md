# 新版本維護設定

- 本資料夾為使用者指定的獨立「心外異常工時與加班費」版本，入口 `index.html`。
- 遵守上層人資保密與工作設定，但本版本修改只在本資料夾；不得修改舊 `HR-Project`。
- 新需求先讀本資料夾 `requirement.md` 及 `log.md` 最近五版，修改後同步更新，完成時詢問是否建立 git commit。沒有授權不得自動 commit 或 push。
- F 是申請；K～O 是核給各段時數，金額依本人當月時薪及已確認倍率計算。不要誤回到舊版 L 時數／M 金額邏輯。
- 手術 T／U 為時間佐證，病患不是同仁；不能用時間吻合直接認定特定同仁實際執行。
- 不將真實員工薪資、病患或病歷識別資料寫入公開程式、測試、Git 或對外網頁。測試一律使用虛構姓名與金額。
- 使用者明確確認的私人姓名對照與本人月份時薪僅存於本機 private-settings.js，此檔由本資料夾 .gitignore 排除；不可強制加入 Git，公開範本維持空白。整包攜帶需保留此檔，公開部署則必須排除。
- 姓名別名先標準化再配對、去重與統計，但保留原始姓名供匯出追溯。時薪補值只套用明確指定的人員與月份，不可自行跨人或跨月外推。
- 發布新版時同步提高 index.html 的可見版本、中繼版本與全部 JS／CSS 資源版本參數，並更新 README。確認指定案例的實際輸出；不得把磁碟測試通過宣稱為使用者已開啟的舊分頁也更新，必要時提醒重開頁面並重新匯入。
